# 太陽系

<video src="../media/solar.mp4" controls loop muted playsinline width="720"></video>

太陽、8 つの惑星、月、冥王星の 11 天体を、2000 年 1 月 1 日から約 12 年分計算しました。左から、内惑星、
外惑星、地球のまわりの月です。

| 項目 | 値 |
|------|----|
| 粒子数 | 11（太陽、水星、金星、地球、月、火星、木星、土星、天王星、海王星、冥王星） |
| 初期条件 | JPL Horizons（DE441）、2000-01-01 12:00 TDB、太陽系の重心が原点、黄道座標 |
| 時間刻み | 0.125 日 |
| ステップ数 | 35000（4375 日、約 12 年） |
| 積分法 | Euler-Cromer（時間刻み一定） |
| 単位 | au、日 |
| エネルギーの相対誤差（最後） | 4.4 × 10^-6 |
| 実行環境 | MN-Core 2（PFCP の実機）、Open MN-Core 2 SDK の MNCL（登戸浦版） |
