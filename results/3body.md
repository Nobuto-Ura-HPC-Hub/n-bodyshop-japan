# 3 体問題（8 の字の解）

<video src="../media/3body.mp4" controls loop muted playsinline width="520"></video>

同じ質量の 3 つの天体が、1 つの 8 の字の軌道の上を追いかけ合う解（figure-8）を、1 周期分計算しました。
3 つの天体は、周期の 1/3 ごとに、互いの初めの位置に入れ替わります。

| 項目 | 値 |
|------|----|
| 粒子数 | 3 |
| 初期条件 | 8 の字の解（周期 6.32591398） |
| 時間刻み | 2^-10（0.0009765625） |
| ステップ数 | 6478（t = 0 〜 6.326、約 1 周期） |
| 積分法 | Euler-Cromer（時間刻み一定） |
| 単位 | N 体の単位（G = 1） |
| 実行環境 | MN-Core 2（PFCP の実機）、Open MN-Core 2 SDK の MNCL（登戸浦版） |
